## 👋 Hey, I'm Ujjwal

A **DevOps & Cloud Engineer** from Bihar, India — passionate about automating everything from code to cloud. I believe infrastructure should be version-controlled, deployments should be boring, and on-call alerts should be silent.

**What I build:**
- 🔧 End-to-end **CI/CD pipelines** using GitHub Actions — push to deploy
- 🐳 Optimized **Dockerfiles** with layer caching — cut build times by ~30%
- ☸️ **Multi-container apps** on Kubernetes with high availability
- ☁️ **Cloud infra** on AWS & IBM Cloud — scalable and reliable
- 📦 Consistent dev environments with **Docker Compose** (3+ services)

**Currently learning:**
- 🏗️ Terraform — Infrastructure as Code
- ☸️ Advanced Kubernetes (RBAC, Helm, custom controllers)
- 🔭 GitOps with ArgoCD
